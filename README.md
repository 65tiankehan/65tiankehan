### 🎬 关于我

- 🧑‍💻 独立开发 **Tengri Desk · 腾格里汗**——一款 Windows 私人影视播放器
- 🎯 专注 **Electron 桌面端**、流媒体播放体验与精致 UI / 动效
- 🤖 把 **Real-ESRGAN 超分 / DeepFilterNet 降噪 / whisper.cpp 字幕** 等 AI 能力做成离线本地功能
- 🌍 原生支持 **简体中文 / English / 日本語** 三语界面
- 🔒 坚信软件可以很强大，但不该以收集用户数据为代价
